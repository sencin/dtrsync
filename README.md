# DTRSync

Employee Attendance and Monitoring System built using `Flutter`, `Spring Boot`, `MySQL`, and `Docker`.

## 1. Application ( Supports for Now Android Operating System)

* **Application Name:** `DTRSync`
* **Application Type:** `Employee Attendance and Monitoring System`
* **Live Link / Download:** `https://github.com/sencin/dtrsync/releases/download/v1.0.0%2B2/app-release.apk`
* **Backend Repository:** `https://github.com/sencin/DTRFirstBackend`

## 2. Source Code

* **GitHub Repository:** `https://github.com/sencin/dtrsync`

The repository contains the source code for the mobile application and backend server.

## 3. Technologies Used

| Technology    | Purpose                                                  |
| ------------- | -------------------------------------------------------- |
| `Flutter`     | Mobile application and user interface                    |
| `Spring Boot` | Backend REST API and application logic                   |
| `MySQL`       | Database for users, attendance, and system records       |
| `Docker`      | Containerization of the backend and database environment |

## 4. Completed Features

* `User Authentication` – Login and registration
* `User Management` – Admin can manage and approve users
* `Time In Out Attendance` – can time in and out with facial recognition support
* `Role-Based Access` – Different access levels for users and administrators
* `Attendance Tracking` – Time-in and time-out recording
* `Attendance History` – View attendance records and monthly attendance
* `Attendance Filtering` – Filter attendance by date range
* `User Search` – Search and filter users
* `Location-Based Attendance` – Record attendance with location information
* `Admin Dashboard` – Administrative monitoring and management
* `Document Management` – Upload and manage documents
* `Equipment Management` – Manage equipment records
* `Real-Time Location Tracking` – Real Time Location Tracking.
## 5. Incomplete Features / Limitations

* `UI/UX Improvements` – Some screens may require additional improvements.
* `Attendance Validation` – Additional handling for duplicate time-in/time-out records is needed.
* `Desktop Support` – Additional configuration for it to build.
* `Production Testing` – Additional testing is required across different devices and deployment environments.
